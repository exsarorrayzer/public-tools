# Discord Bot Management Multitool

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```

## Features

- Single token validation and live status check
- Bulk token validation from txt file
- List all servers bot is in
- Display bot permissions per server
- Create server invite links
- Grant permissions to users

## Token File Format

Create a `tokens.txt` file with one token per line:

```
# Comment lines start with #
MTIzNDU2Nzg5MDEyMzQ1Njc4.GhIjKl.MnOpQrStUvWxYzAbCdEfGhIjKlMnOpQrStUv
# Another comment
OTg3NjU0MzIxMDk4NzY1NDMy.XaBcDe.FgHiJkLmNoPqRsTuVwXyZaBcDeFgHiJkLm
```

## Requirements

- Node.js 18+
- Valid Discord Bot Token
